# sprite2bif.sh

This is a tool that will convert a Tubi CMS thumbnail sprite strip into a Roku-compatible BIF thumbnail file.

This is for demonstration and only and will only process one sprite strip.     
# Sample Tubi CMS sprite URL: http://images.adrise.tv/mHqxdM3p0GZhXrkz3ICH49arh5g=/img.adrise.tv/301333/5x-0.jpg
#                                                                               

Depends on biftool executable from https://sdkdocs.roku.com/display/sdkdoc/Trick+Mode+Support

Example usage:

```
$ bash sprite2bif.sh 'http://images.adrise.tv/mHqxdM3p0GZhXrkz3ICH49arh5g=/img.adrise.tv/301333/5x-0.jpg'
```
